Demo de Auth API Security

La API de inicio de sesión de una tienda, funcionando en esta computadora. Primero se usa como lo haría un cliente; después se la ataca con técnicas reales para ver cómo responde. Todo ocurre sobre cuentas de práctica y nada sale a internet.
